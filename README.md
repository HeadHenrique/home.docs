# home.docs

Biblioteca visual de documentos: pastas, categorias, upload, pré-visualização, renomeação, download e união de arquivos em PDF.

## Desenvolvimento

```bash
npm install
npm run dev
```

Versão inicial com armazenamento local no navegador (IndexedDB). Sem sincronização em nuvem ou autenticação nesta fase. Não utilize como único backup de documentos importantes.
